# Web Development Slides

## Background
These slides were created for the Web Development workshop session of STEP 1 2026 at Florida International University in Miami, Florida.

## Notes
This workshop made extensive use of computing resources provided through a temporary allocation on Jetstream2 that was available during the two-week workshop period. As a result, some slides reference specific Jetstream2 instances, URLs, and resources that are no longer active due to the limited duration of the allocation.

Despite the expiration of these resources, the overall content and learning objectives of the workshop remain relevant. The primary goal of the activity was to provide participants with hands-on experience in modern web development by guiding them through the setup of a development environment and demonstrating how AI-assisted coding tools can be used to build and extend web application features.
